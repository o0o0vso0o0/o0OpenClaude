会话重命名 · UI 方案示例

可交互预览（不连后端）。在各卡片内按说明操作。风格贴近 OpenClaude GUI 侧栏。 文件：o0/Temp/session-rename-ui-demos.html

方案 A · 推荐

双击标题就地编辑

侧栏会话名或顶栏大标题双击 → 输入框；Enter 保存，Esc 取消。

进行中遗弃

腿部 IK 调参

双击左侧会话名，或双击上方标题试试。
操作：双击侧栏标题或顶栏标题
方案 B

悬停「⋯」菜单

悬停会话行出现 ⋯ → 重命名 / 移入遗弃。不和拖拽抢双击手势。

进行中遗弃

OpenClaude GUI

把鼠标移到左侧会话行，点右上角 ⋯ → 重命名。
操作：悬停会话 → ⋯ → 重命名
方案 C

顶栏铅笔按钮

只改当前打开会话。实现简单，不碰侧栏拖拽。可与 A 组合。

进行中遗弃

木方块原点导出

点顶栏标题旁的铅笔进入编辑。
操作：点顶栏 ✎
方案 D

慢双击 / 选中后再点

第一次点击选中；约 0.5s 后再点同一项进入编辑（类似资源管理器）。

进行中遗弃

Agent 活动条

先点选会话，稍等再点一次同一会话名进入重命名（不要快速双击）。
操作：单击选中 → 停顿 → 再单击标题文字进入编辑

选好方案后告诉我编号（可组合，如 A+C），再接到正式 GUI。
